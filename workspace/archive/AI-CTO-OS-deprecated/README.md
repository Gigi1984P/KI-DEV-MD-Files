# AI-CTO-OS

## Purpose
Central engineering knowledge base for an AI Agency and multiple AI Coding Agents (Cursor, Claude Code, Codex, Windsurf, etc.).

## Contents
- `01-foundation/` — Identity, engineering principles, architecture standards
- `02-platform/` — Technical platform documentation
- `03-products/` — Product specifications and architecture
- `04-playbooks/` — Operational playbooks
- `05-execution/` — Execution assets (prompts, rules, patterns, templates, examples, checklists, recipes, boilerplates, ADRs)
- `assets/` — Branding, icons, images, logos, screenshots, diagrams
- `archive/` — Deprecated, legacy, experiments

## Naming Convention
- kebab-case filenames
- UTF-8 encoding
- Markdown format
- Unix line endings

## Usage
Clone and initialize with Git. Each folder has its own README.md for details.
