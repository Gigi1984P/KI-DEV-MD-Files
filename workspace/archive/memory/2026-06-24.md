## Website Deployment - Gianluigi Plantone (plantone.de)

### Initialer Versuch: Laravel
- Laravel-Installation im Verzeichnis `homepage/` auf dem Server entdeckt
- Versuch, Laravel auf Hetzner Shared Hosting (konsoleH) zu deployen
- **Blocker:** Apache Config, PHP-FPM, fehlende Framework-Services - Laravel kann auf Shared Hosting nicht laufen
- Entscheidung: WordPress stattdessen verwenden (auf Wunsch des Users)

### WordPress Installation & Setup
- WordPress in `public_html/` installiert (Startverzeichnis in konsoleH angepasst)
- Datenbank: `plantoa_db0` auf `lij7.your-database.de`, User `plantoa_0`
- DB-Verbindung bestätigt, aber externe Verbindungen blockiert (nur localhost)
- **Kritisches DB-Problem entdeckt:** `post_content_filtered` hat keinen Default-Wert → INSERTs schlugen fehl, `$conn->insert_id` gab 0 zurück
- **Emoji-Problem:** DB verwendet `utf8` (nicht `utf8mb4`) → 4-Byte UTF-8 (Emojis) verursachen `Incorrect string value` Fehler
- Lösung: Keine Emojis in Content verwenden, stattdessen Plain Text mit deutschen Umlaut-Escapes
