# Patterns

## Purpose
Enterprise pattern catalog with deep structure.

## Format
Each pattern contains:
- `README.md` — Overview
- `Problem.md` — What problem this solves
- `Context.md` — When to apply
- `Forces.md` — Trade-offs and constraints
- `Solution.md` — The solution
- `Diagram.md` — Visual representation
- `Example.md` — Working example
- `Pros.md` — Advantages
- `Cons.md` — Disadvantages
- `Anti-Patterns.md` — What to avoid
- `Checklist.md` — Implementation checks
- `Related-Patterns.md` — Connected patterns
