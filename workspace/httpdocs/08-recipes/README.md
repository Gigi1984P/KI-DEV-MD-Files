# Recipes

## Purpose
Step-by-step build recipes for common projects.

## Structure
Each recipe is a folder with:
- `README.md` — Overview and prerequisites
- Step-by-step instructions
- Decision points
- Validation criteria

## Recipes
build-saas, build-crm, build-rag, build-agent, build-api, build-dashboard, build-stripe, build-auth, build-search, build-mcp

## Usage
Follow from start to finish for consistent outcomes.
